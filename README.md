# Ветеринарный кабинет «Алиса» — сайт

Статический сайт без сборки: HTML + один CSS + небольшой JS (мобильное меню). Адаптивный: телефон, планшет, ПК.

- `css/style.css` — единый стиль (цвета, кнопки, сетки).
- `img/` — маскот, иконки, фото команды (WebP).
- Шрифты Inter и Oswald подгружаются с Google Fonts; без сети используются системные.
