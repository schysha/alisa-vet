# Сайт ветеринарного кабинета «Алиса»

Многостраничный статический сайт на HTML, CSS и JavaScript. Не требует npm или сборки.

## Страницы
- `index.html` — главная
- `services.html` — услуги
- `therapy.html` — терапевтический приём
- `vaccination.html` — вакцинация
- `diagnostics.html` — диагностика
- `surgery.html` — хирургическая помощь
- `specialists.html` — специалисты
- `about.html` — о кабинете
- `prices.html` — цены
- `contacts.html` — контакты

Общие стили: `css/style.css`; скрипт: `js/script.js`. Откройте `index.html` в браузере. Для публикации загрузите все файлы и папки на хостинг, сохранив структуру.

Перед публикацией проверьте актуальность адреса, телефонов, расписания, цен и списка услуг. Сведения о специалистах не добавлены, поскольку подтверждённые данные не предоставлены. Онлайн-запись, CRM, форма отправки заявок и карта не подключены.
